# 商品介绍草稿

## 标题

FlowHarbor 流港调度｜基于 Crawlab 的 Python 采集任务管理平台｜私有部署源码

## 简介

将分散的 Python 采集脚本集中管理，在一个中文工作台内完成项目分组、脚本上传、定时调度、节点选择、执行状态跟踪和结果查看。适合已有采集脚本、希望建立统一运行环境的开发者及小团队。

## 交付内容

- Vue 3 + TypeScript 管理界面源码。
- FastAPI 接入服务源码与测试。
- Crawlab Master / Worker 的 Docker Compose 部署工程。
- 可运行的 Python 采集示例和内置示例网页。
- 中文部署、使用、备份恢复、架构与发布文档。
- 依赖版本记录、第三方许可说明和源码 ZIP。
